Where images live

Images are uploaded to Squarespace and served from its CDN at full Instagram-grade quality, with retina srcset. Unlimited items, tiny embed.

  1. Download thumbnails — numbered 1080×1350 JPEGs.
  2. Upload the folder to a static host (Cloudflare Pages, Netlify), or to Squarespace via Link → Files.
  3. Static host: paste the folder URL above, hit Apply — done.
    Squarespace: copy each URL, then Paste URLs in bulk.

Images are baked into the code block as data URIs. No uploading — but Squarespace caps a Code block at 400 KB, so quality and item count trade against each other.

Item counts are averages from real photographs; detailed images cost more. The meter below is the truth.
